# 简历项目描述

## 项目介绍

**史鉴 RAG——面向历史学习的可溯源智能问答系统**

基于 Qwen、FastAPI、SQLite FTS5 与 Chroma 构建混合 RAG 链路，支持事件级引用、离线评测、无答案拒答及模型故障降级。

## 推荐简历要点

- 对 100 条结构化历史事件构建年份/专名精确匹配、FTS5 全文检索和 Chroma 向量召回链路，使用加权 RRF 融合排序并返回事件级引用。
- 建立 321 条闭集离线回归评测，混合检索 Hit@5 达到 100%、MRR@5 达到 99.84%，将无答案拒答准确率由规则基线的 90% 提升至 100%；本机检索 P95 为 7.13 ms。
- 使用 FastAPI 提供结构化问答与健康检查接口，通过 trace ID 和 JSON 日志记录检索/生成耗时，实现模型超时、限流及密钥缺失场景下的可溯源本地降级。
- 通过内容哈希和稳定 ID 增量同步 SQLite/Chroma 索引，并使用 Pytest、评测阈值门禁、Docker 与 GitHub Actions 保证公开仓库可复现。

## 30 秒项目介绍

这个项目解决的是大模型回答历史问题时“答案看起来合理但无法证明来源”的问题。我把结构化年份查询、FTS5 和 Chroma 向量召回组合起来，用 RRF 合并结果，并要求 Qwen 只能根据召回证据回答。没有可靠证据或模型不可用时，系统会拒答或切换到带引用的本地模板。项目包含 321 条自动回归评测和 FastAPI、Docker、CI 等完整工程链路。

## 指标使用边界

上述指标来自项目内置 100 条事件派生的闭集回归测试，适合证明检索实现和回归稳定性，不应描述成“开放域历史问答准确率”。面试时应主动说明这一限制。
